# Linked Lists

Linked Lists are linear data structures where each node contains data and a reference (pointer) to the next node.

---

## Time Complexity

| Operation | Complexity |
|-----------|------------|
| Access | O(n) |
| Search | O(n) |
| Insert at Head | O(1) |
| Insert at Tail | O(n) |
| Delete at Head | O(1) |
| Delete at Tail | O(n) |
| Reverse | O(n) |

---

## Common Interview Patterns

- Fast & Slow Pointer
- Dummy Node
- In-place Reversal
- Merge Lists
- Cycle Detection

## Key Takeaways

- Linked Lists do not support random access.
- Insertion and deletion at the head are O(1).
- Fast & Slow Pointer is one of the most important interview patterns.
- Dummy Nodes simplify insertion and merging logic.
- Reversing a linked list is a fundamental interview problem.
