# Topics

## Prompt Chaining

Prompt chaining breaks a complex task into multiple sequential prompts.


Input
  ↓
Prompt 1
  ↓
Output
  ↓
Prompt 2
  ↓
Output

**File:** `prompt_chaining.md`

---

## Prompt Templates

Prompt templates provide reusable structures for generating prompts dynamically.

They allow applications to separate:

* Prompt structure
* User input
* Dynamic variables

**File:** `prompt_templates.md`

---

## Tokens & Tokenization

Tokens are the units processed by language models.

Tokenization converts text into tokens before the model processes it.

**File:** `tokens_and_tokenization.md`

---

## Embeddings

Embeddings represent information as numerical vectors.

They are commonly used for:

* Semantic search
* Similarity search
* Recommendations
* RAG

**File:** `embeddings.md`

---

## Vector Databases

Vector databases store and efficiently search vector embeddings.

They are commonly used for:

* Semantic search
* Similarity search
* RAG
* Recommendation systems

**File:** `vector_databases.md`

# Learning Strategy

For each Generative AI topic:

1. Understand the underlying concept.
2. Learn the terminology.
3. Study practical use cases.
4. Understand how the concept fits into backend systems.
5. Implement small examples where appropriate.
6. Connect the concept to larger AI architectures.

The goal is to understand how Generative AI components can be integrated into production-oriented backend applications.
