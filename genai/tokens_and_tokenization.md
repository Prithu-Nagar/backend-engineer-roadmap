# Tokens and Tokenization

## What is a Token?

A token is the smallest unit of text processed by a Large Language Model (LLM).

A token can represent:

- A word
- Part of a word
- A punctuation mark
- A number
- A special character

Example

Input:

```
ChatGPT is amazing!
```

Possible Tokens:

```
Chat
GPT
is
amazing
!
```

---

## What is Tokenization?

Tokenization is the process of converting text into tokens before it is processed by an LLM.

Workflow

```
User Prompt
      │
      ▼
Tokenizer
      │
      ▼
Tokens
      │
      ▼
Large Language Model
      │
      ▼
Generated Tokens
      │
      ▼
Readable Response
```

---

## Words vs Tokens

Words and tokens are not always the same.

Example

```
unbelievable
```

Possible Tokens

```
un
believ
able
```

---

## Context Window

The Context Window is the maximum number of tokens an LLM can process in a single conversation.

It includes:

- System Prompt
- User Prompt
- Conversation History
- Model Response

---

## Input Tokens

Tokens sent to the model.

Example

```
Explain Python Generators.
```

---

## Output Tokens

Tokens generated by the model.

Example

```
Generators produce values lazily...
```

---

## Why Tokens Matter

- Determines API cost
- Determines maximum context length
- Affects response quality
- Important for prompt optimization
