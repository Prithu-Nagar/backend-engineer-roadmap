## Review checklist

For each problem, record:

- [ ] First approach and why the pattern fits.
- [ ] Invariant, state transition, or graph traversal rule.
- [ ] Time and auxiliary-space complexity.
- [ ] Empty input, duplicates, boundaries, and disconnected cases considered.
- [ ] Final implementation tested against a small example.
- [ ] One improvement or lesson recorded.

Reuse existing implementations under `dsa/` where available. Do not add duplicate solution files solely for this assessment. The Day 81 practice module is `dsa/full_interview_set.py`.
