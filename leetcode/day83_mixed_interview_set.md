# Day 83 — Mixed Interview Set

**Goal:** Complete five mixed problems under interview conditions. Choose
problems that expose weak patterns; use the suggestions below as a balanced
default set.

## Problems

1. **Binary Tree Level Order Traversal** — binary tree, BFS, queue.
2. **Validate Binary Search Tree** — tree recursion, lower/upper bounds.
3. **Number of Connected Components in an Undirected Graph** — graph traversal
   or Union-Find.
4. **Course Schedule** — directed graph, cycle detection, topological sort.
5. **Longest Consecutive Sequence** — hashing and expected linear-time lookup.

## Timed workflow

- Spend 3–5 minutes clarifying constraints and examples.
- State the brute-force idea before optimizing.
- Implement the selected approach without looking at a solution.
- Test empty input, a single item, duplicates, disconnected components, and
  cycles where applicable.
- Explain time and space complexity in terms of nodes/vertices and edges.
