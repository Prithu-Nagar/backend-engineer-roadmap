# Day 84 — Mixed Interview Set

**Goal:** Complete five mixed problems under timed conditions, prioritizing arrays, hashing, and sliding-window patterns.

## Problems

1. **Two Sum** — array traversal and hash map; expected `O(n)` time.
2. **Group Anagrams** — canonical signatures and hash-based grouping.
3. **Longest Substring Without Repeating Characters** — variable-size sliding window.
4. **Minimum Size Subarray Sum** — shrinking window for positive values.
5. **Longest Consecutive Sequence** — hash set and sequence-start detection.

## Timed workflow

- Spend 3–5 minutes clarifying constraints and edge cases.
- State the brute-force approach, then explain the optimization.
- Implement without looking at a solution.
- Test empty input, duplicates, all-negative values where relevant, and minimal valid input.
- State time and auxiliary-space complexity.
