# Day 85 — Mixed Interview Set

**Goal:** Solve five mixed problems with emphasis on binary search, intervals, and greedy reasoning.

## Problems

1. **Search Insert Position** — binary search boundary; target `O(log n)` time.
2. **Find First and Last Position of Element in Sorted Array** — lower/upper boundaries.
3. **Merge Intervals** — sort by start and merge overlapping ranges.
4. **Non-overlapping Intervals** — greedy selection by earliest finishing time.
5. **Jump Game** — track the farthest reachable index.

## Timed workflow

- Spend 3–5 minutes clarifying constraints and edge cases.
- State the brute-force approach, then explain the optimization and invariant.
- Implement without looking at a solution and test boundary cases.
- State time and auxiliary-space complexity.
