# Day 87 — LeetCode Interview Simulation

**Goal:** Simulate a real interview block: clarify constraints, propose an approach, code without notes, test edge cases, and state complexity.

## Timed format

- **Total:** 60–75 minutes.
- **Problem 1:** Two Sum — hashing; 10 minutes.
- **Problem 2:** Longest Substring Without Repeating Characters — sliding window; 15 minutes.
- **Problem 3:** Binary Tree Level Order Traversal — BFS; 15 minutes.
- **Problem 4:** Course Schedule — graph topological sort; 20 minutes.
- **Stretch:** Coin Change — dynamic programming; 20 minutes if time remains.

## Interview protocol

1. Restate the problem and ask about input constraints.
2. Describe a straightforward approach, then justify the optimized approach.
3. State the invariant or recurrence before implementation.
4. Write readable code with meaningful names and explicit edge-case handling.
5. Test empty/minimal input, duplicates, disconnected graphs, and impossible states where applicable.
6. State time and auxiliary-space complexity.
7. Record whether the solution was independent, hinted, or reviewed.
