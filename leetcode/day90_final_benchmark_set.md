# Day 90 — Final LeetCode Benchmark Set

## Goal

Establish a final baseline across the major interview patterns. Solve without notes first, explain the approach and complexity, and record the result honestly.

## Benchmark set

| Pattern | Problem | Target time | Key reasoning |
|---|---|---:|---|
| Hash map | Two Sum | 10 min | Complement lookup and duplicate values |
| Sliding window | Longest Substring Without Repeating Characters | 15 min | Window invariant and last-seen indices |
| Binary tree | Binary Tree Level Order Traversal | 15 min | Queue and level boundaries |
| Graphs | Course Schedule | 20 min | Topological sort and cycle detection |
| Dynamic programming | Coin Change | 20 min | State, transition, base case, unreachable amount |

## Timed protocol

1. Set a timer before opening each problem.
2. State a brute-force baseline and its complexity.
3. Explain the invariant or recurrence before coding.
4. Implement independently and test empty, minimal, duplicate, and boundary inputs.
5. Explain time and auxiliary-space complexity separately.
6. Record whether the solution was independent, slow, or hint-assisted.
