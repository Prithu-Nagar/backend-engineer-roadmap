# Resume Technical Skills Mapping

Map skills to evidence in the repository before adding them to a resume. A topic in a study note is not, by itself, proof of production experience.

## Evidence Mapping

| Skill area | Repository evidence | Resume wording guidance |
| --- | --- | --- |
| Python | `python/` examples, interview notes, project modules | Name language features you can explain and demonstrate. |
| Backend APIs | `backend/`, Task Manager and URL Shortener artifacts | State the framework and endpoints actually implemented. |
| SQL and data modeling | `sql/` query exercises and project schemas | Mention joins, CTEs, window functions, transactions, or optimization only when you can explain the examples. |
| DSA | `dsa/` implementations and `leetcode/` practice | Keep problem-solving claims separate from production engineering experience. |
| System design | `system-design/` HLD/LLD and mock interviews | Label design-only artifacts as design work, not deployed systems. |
| Testing and quality | Project tests, pytest configuration, Ruff/pre-commit setup | State tools and test coverage only after verifying the actual run and scope. |
| GenAI | `genai/` RAG, agents, embeddings, and tool-integration artifacts | Distinguish prototypes and learning exercises from production deployments. |

## Resume Preparation Checklist

- [ ] Every listed skill has a concrete code, test, query, or design artifact.
- [ ] Framework names match the implementation, not just the learning notes.
- [ ] Project bullets describe implemented behavior separately from proposed architecture.
- [ ] Metrics are backed by repeatable measurements and include workload/context.
- [ ] No confidential client information, secrets, access tokens, or proprietary code is included.
- [ ] The skills section is concise and prioritizes requirements from the target job description.

## Interview Readiness

For each skill, prepare one example, one trade-off, one failure mode, and one way to test or measure the behavior. Prefer depth on skills demonstrated by a project over a long list of unsubstantiated keywords.
